# Archive

This directory contains historical planning material kept for context. It is **not** a current roadmap or a statement of supported features.

`feature-planning-notes.txt` predates the essentials-only refactor and includes features that were intentionally removed, such as quizzes, attendance, timetables, analytics dashboards, report cards, promotion workflows, SMS and other out-of-scope capabilities.

For the current feature set, see the root [README](../../README.md) and [ARCHITECTURE.md](../ARCHITECTURE.md).
